# andrewlawler.github.io

This is my personal blog site I built using Publish. This was a project I decided to do to try and explore Publish since i'd seen it within the community for the past few years. I wanted to see how it would actually work.


## The Site

The site has 3 main pages. The home page shows some recent articles alongisde a welcome piece. The articles page shows all recent articles and then the about page just tells you a little more about me. 

## Conclusion

I really enjoyed building this site as a small mini project and I will aim to post some content onto it in the future.
